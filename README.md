# Projeto Aplicado II – Análise de Sentimento em Avaliações de Filmes e Séries

Este repositório contém os materiais referentes ao **Projeto Aplicado II** do curso de **Ciência de Dados** da Universidade Presbiteriana Mackenzie.

O projeto tem como objetivo desenvolver uma solução de **análise de sentimento em avaliações textuais de filmes e séries**, utilizando técnicas de **Processamento de Linguagem Natural (NLP)** e **Aprendizado de Máquina**.

Este repositório será atualizado conforme as próximas etapas do projeto forem sendo desenvolvidas.

---

# 🎯 Objetivo do Projeto

O objetivo principal é desenvolver um modelo capaz de **classificar automaticamente o sentimento de avaliações de usuários**, identificando se um comentário possui **sentimento positivo ou negativo**.

O projeto busca aplicar conceitos de:

- aquisição e preparação de dados
- análise exploratória de dados
- processamento de linguagem natural (NLP)
- aprendizado de máquina
- engenharia de software aplicada à ciência de dados

---

# 🏢 Organização Escolhida

A organização considerada no projeto é a **Netflix**, empresa global de streaming de filmes e séries.

Empresas desse setor utilizam **análise de dados e machine learning** para entender preferências dos usuários, melhorar recomendações e avaliar a recepção de conteúdos.

Neste projeto, a análise será aplicada a **avaliações textuais de usuários sobre filmes e séries**.

---

# 📊 Dados Utilizados

O projeto utilizará **dados textuais de avaliações de usuários**.

Esses dados são compostos por comentários escritos sobre filmes ou séries e suas classificações de sentimento.

Exemplo de variáveis (metadados) do dataset:

| Variável | Descrição |
|--------|--------|
| review_text | Texto da avaliação do usuário |
| sentiment | Classificação do sentimento (positivo ou negativo) |
| review_length | Tamanho da avaliação |
| movie_title | Filme ou série avaliada |

Esses dados permitirão aplicar técnicas de **Processamento de Linguagem Natural (NLP)** para análise automática de sentimentos.
